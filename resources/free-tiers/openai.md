# OpenAI Free Tier

**Type**: API
**Last Verified**: 2026-02-01
**Verified By**: Codex
**URL**: platform.openai.com/docs/pricing

---

## Overview

OpenAI's API is pay-as-you-go with prepaid billing. The pricing pages list
token and tool costs, and do not describe a free token tier for API usage.
There are limited free allowances for specific built-in tools and AgentKit
storage.

---

## What's Offered (Free Allowances)

- **File Search Storage**: First 1 GB free, then billed at $0.10 per GB-day.
- **AgentKit ChatKit Storage**: 1 GB free per account per month for file/image
  uploads, then billed at $0.10 per GB-day.

See pricing details: `platform.openai.com/docs/pricing` and
`openai.com/api/pricing/`.

---

## Limits / Notes

- **API usage requires prepaid credits**; minimum purchase is $5.
- **Credits expire after 1 year** and are non-refundable.
- **If free credits exist in an account**, they are used before paid credits
  (availability may vary by account/time).
- **AgentKit billing begins Nov 1, 2025** (no charges before then).

Billing details: `help.openai.com/en/articles/8264778-what-is-prepaid-billing`

---

## Sign-Up Process

1. Create an OpenAI account.
2. Add billing details and purchase prepaid credits (minimum $5).
3. Generate an API key and start using the API.

---

## API Access

Programmatic access is via the OpenAI API with an API key. Pricing is based on
token usage plus any built-in tool usage.

---

## Terms of Service Notes

- Prepaid credits expire after 1 year and are non-refundable.
- Trust tier can affect maximum prepaid balance and rate limits.
